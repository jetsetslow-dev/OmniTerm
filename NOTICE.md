a build made from this repository from replacing the Play Store package, while

proprietary SDKs (billing, ads, consent, in-app review), which are not part of
this repository.

## Unicode data

The terminal's table of double-width characters
(`app/src/main/java/com/jetsetslow/omniterm/data/term/UnicodeWidthTable.kt`) is generated by
`scripts/generate-unicode-width.py` from the Unicode Character Database, version 16.0.0
(`EastAsianWidth.txt` and `emoji-data.txt`).

## Broadcast typing idea

Sending typing to several open terminals was inspired by tmux synchronize-panes
(https://github.com/tmux/tmux), ClusterSSH (https://github.com/duncs/clusterssh) and
ServerBox (https://github.com/lollipopkit/flutter_server_box). These are references for the
idea only; no source code or dependency from these projects is included by this feature.
