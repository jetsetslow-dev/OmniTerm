Building from source

Requirements and exact commands are in the README and CONTRIBUTING.md. The app is Kotlin with Jetpack Compose.

Build the open-source variant

./gradlew assembleOpenSourceDebug testOpenSourceDebugUnitTest --no-daemon

Before sending a change

./scripts/local-pr-check.sh --full

This runs the release and CI contract tests, both flavour unit suites and lint gates, the release SBOM dependency graphs, an advisory check of dependencies and pinned GitHub Actions, and the CodeQL analysis CI uses. With a device or emulator attached it also runs the Room migration matrix.

Architecture in brief

  • Connections: JSch (the maintained com.github.mwiede fork) for SSH, SFTP and port forwards; smbj, Apache Commons Net and OkHttp for shares behind a common file-system abstraction.
  • Storage: Room (SQLite) with versioned, tested migrations.
  • VPN tunnels: a Go library (tunnel/) built on wireguard-go and gVisor's network stack, bound with gomobile.
  • Decisions: architecture decision records are in docs/adr; releases follow the release runbook.

Dependency licences are listed in THIRD_PARTY_NOTICES.md.
