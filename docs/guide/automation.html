Automation and MCP

Both features are off until you turn them on, and turning them on asks for your App Lock PIN or fingerprint, or the phone's screen lock.

Automation (Tasker and other apps)

Under Tools → Automation, make one token per job: it runs one saved script on the hosts you pick and nothing else. The token is shown once; OmniTerm keeps only a fingerprint. Revoke stops it at once.

  • Only scripts safe to run unattended are accepted: destructive-looking scripts are refused and every {{value}} needs a default.
  • Tasker: add an action, choose Plugin, then OmniTerm, and paste the token. It sets %output, %exit and %failed_hosts.
  • Other apps or adb: broadcast com.jetsetslow.omniterm.action.RUN_SCRIPT to the package com.jetsetslow.omniterm with the token in com.jetsetslow.omniterm.extra.TOKEN. Add REPLY_PACKAGE and REPLY_ACTION extras to get the result back at your app only.
  • A token OmniTerm does not know gets no answer. Each run is kept in Fleet history, marked as an automation. Keep tokens private: anyone holding one can run its script.

AI assistants (MCP)

Under Tools → AI assistants, an assistant such as Claude Code, Gemini CLI or Codex can read the hosts you tick and ask to run your saved scripts, using the Model Context Protocol.

  • The server listens only on the phone's loopback address, needs its token on every request and refuses requests that name another host or come from a web page. A notification shows while it is on.
  • Only ticked hosts are visible (none by default): name, group, state, health, latency, recorded metrics and alerts, and containers. Addresses, user names, passwords, keys, notes and script commands are never given.
  • Every run waits for your approval on the phone, with the full command shown. Denied or unanswered for two minutes means it does not run.
  • To reach it from a computer, pick one of your own hosts and OmniTerm keeps a reverse SSH tunnel open to it; the screen shows the command for Claude Code, Gemini CLI and Codex.
  • Whatever an assistant reads goes to that assistant program and may reach the company behind it. Share only what you are comfortable with.

Links and sharing

ssh:// links and text or files shared from other apps only open a screen. Nothing connects, saves or uploads until you tap, and a password in a link is dropped.
