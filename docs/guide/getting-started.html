Getting started

OmniTerm is an Android app. It connects straight from your phone or tablet to your own servers; there is no OmniTerm account and nothing to install on the servers.

Choose a build

Two builds share the same features. They differ in how they are distributed and paid for.

BuildWhere fromSaved hostsAds
Open-source buildGitHub releases (APK)UnlimitedNone
Play Store buildGoogle Play1 when free; unlimited after the one-time UnlockOne banner, removed by either purchase

The open-source build uses the application ID com.jetsetslow.omniterm.app.oss, so it can sit beside the Play Store package. It contains no Play Billing code and no ad SDK. The Unlock purchase also enables Quick connect, Telnet and USB serial terminals in the Play Store build. The Play Store build adds Google's proprietary billing, ads, consent and in-app review libraries, which are not part of the repository. The licence is stated on the home page.

Install the APK

  1. Download the latest APK from the GitHub releases page.
  2. Allow installs from your download source in Android settings.
  3. Open the APK and install it.

Add your first host

  1. Open Servers and add a host: a display name, hostname or IP address, SSH port, user name and sign-in method.
  2. Sign in with a password, an imported SSH key or a reusable credential profile. See Hosts and sign-in.
  3. The first time you connect, OmniTerm pins the host key. A changed key later is rejected until you review it.
  4. Open Term for a shell, Monitor for live metrics or Files to browse.

Already have hosts in ~/.ssh/config? You can import them; see Import from ssh_config.

What the servers need

An SSH server and a user that can sign in. Monitoring reads standard Linux /proc and utility output, so no agent runs on your servers. Linux gives the richest metrics; macOS, BSD and Windows (OpenSSH Server and Windows PowerShell) are also supported, with some features unavailable on Windows, such as cron, tmux, sudo mode and containers.
