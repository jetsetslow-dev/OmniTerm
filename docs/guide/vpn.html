VPN tunnels

Reach hosts that are only available over WireGuard, such as a home server, without using Android's VPN.

  1. Add the tunnel once under Tools → VPN tunnels: paste or import the .conf from your router or VPN server. OmniTerm checks it and explains problems line by line. It never runs PostUp or similar commands.
  2. Pick it per host in the host's settings under VPN tunnel. Terminal, files, port forwards, Fleet runs and background checks then go through it. If the host has another address inside the tunnel, enter it under Address through the tunnel.

Behaviour to know

  • Never direct: a host with a tunnel always goes through it. If the tunnel cannot connect, the connection fails and says why. Choose None (direct) to connect directly again.
  • To use one machine both at home and away, save it twice: once with the tunnel, once with None (direct).
  • The tunnel runs only inside the app; the rest of the phone and other VPN apps are unaffected. It starts when needed and stops after five minutes unused.
  • TCP port and certificate checks of a tunnelled host use the tunnel; ping, DNS and web checks of its own address do not run yet and say so.
  • A tunnel a host still uses cannot be deleted.
  • The configuration, including its private key, is stored encrypted on the device and travels with the hosts in an encrypted backup.
