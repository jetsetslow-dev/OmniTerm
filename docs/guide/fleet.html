Fleet and scripts

Broadcast

Fleet → Broadcast runs a command on the online hosts or groups you pick, with live output per host. Each card shows the exit status or says the connection was lost. Destructive commands (disk wipes, prunes, deletes, firewall lockouts and similar) get a warning before they run.

  • Run in tmux keeps each host's command running if the connection drops and reconnects for up to 30 minutes.
  • Rolling run runs on 1, 2, 5 or 10 hosts at a time and can stop at the first failing batch.
  • Retry re-runs only on the hosts that failed or were not run.
  • Share output sends the run as text to any app.
  • History keeps your last 50 runs, with Use again to load one back without running it. Values typed for placeholders are not kept.

Scripts

Under Tools → Scripts save scripts and mark them for quick per-host use, Fleet, or both, and choose the OS or system each is for (Linux, FreeBSD, macOS, Windows, Proxmox, Home Assistant, TrueNAS, OpenWrt, pfSense and others). A script runs only on hosts it is meant for.

Values asked at run time

Write {{name}} in a script, for example qm start {{vmid}}, and OmniTerm asks for the value on each run; {{name=default}} sets a starting value. Each value reaches the host as one quoted word, so it can never run as a command of its own.
